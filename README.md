# Castle Defense

A browser-based tower defense game. Single HTML file, no build step, no server — open it and play.

## Play it live
https://bnjmnsmmr.github.io/castledefense/

## Run it locally
Just double-click `index.html`, or open it in any browser.

## Features
- 8 towers (+1 secret) with per-level unlockable attacks
- 9 enemy types across escalating Worlds
- Auto-wave, achievements, an in-game admin panel (gear icon) for tuning difficulty
- Progress autosaves to your browser
